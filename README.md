# Slicewise, in the browser

The web build of Slicewise, a DICOM viewer: <https://poholos.github.io/slicewise-demo/>

Press **Demo** to open a synthetic examination of an invented patient: MR, CT and radiographs, generated in the page. Or open your own with **Open files…**, or with **Open folder…**, which takes a whole folder at once. Files can be dropped on the page as well, but a folder cannot: the browser hands one over with nothing behind it. They stay in your browser; nothing is uploaded anywhere.

Slicewise is for viewing, teaching, research and reviewing your own images. It is not a medical device and is not intended for diagnosis or treatment decisions.

This repository holds only the built bundle, which the viewer's CI pushes here after every change to its main branch, replacing the single commit. Nothing here is meant to be edited. The source is not published.
